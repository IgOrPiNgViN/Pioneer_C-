## 1. Почему ломается русский текст

Русские буквы проходят через **три места**. Если кодировки не совпадают — на экране мусор.

| Этап | Что это | Типичная кодировка |
|------|---------|-------------------|
| 1. Файл `.cpp` | Как сохранены буквы на диске | UTF-8 или Windows-1251 |
| 2. Компилятор | Как компилятор читает строковые литералы `"Привет"` | нужен флаг `/utf-8` в VS |
| 3. Консоль | Как окно вывода рисует байты | UTF-8 (65001) или CP866 / CP1251 |

**Итог:** мало «вписать русский в код» — нужно согласовать файл + компилятор + консоль.

## 2. Обязательная база: кодировка файла и Visual Studio

Эти шаги нужны **почти для всех вариантов ниже**.

### 2.1. Сохранить `.cpp` в UTF-8

**Visual Studio:**

1. Открой файл `.cpp`.
2. Меню **Файл → Сохранить как…** / **File → Save As…**
3. Нажми стрелку у кнопки **Сохранить** → **Сохранить с кодировкой…** / **Save with Encoding…**
4. Выбери один из вариантов:
   - **UTF-8** (без BOM) — предпочтительно вместе с `/utf-8`
   - **UTF-8 with signature (BOM)** — тоже часто работает в VS

Старый путь (если есть в меню):  
**File → Advanced Save Options → Unicode (UTF-8 …) — Codepage 65001**.

**VS Code / Cursor:**

1. В правом нижнем углу кликни на кодировку (`UTF-8`, `Windows 1251` и т.д.).
2. **Save with Encoding** → **UTF-8**.

### 2.2. Флаг компилятора `/utf-8` (Visual Studio)

Чтобы компилятор MSVC правильно читал UTF-8 в исходниках:

1. ПКМ по проекту → **Свойства** / **Properties**.
2. **C/C++ → Командная строка** / **Command Line**.
3. В **Дополнительные параметры** добавь:

```text
/utf-8
```

4. **Применить → ОК**.

### 2.3. Шрифт консоли

В свойствах окна консоли (ПКМ по заголовку → **Свойства → Шрифт**) выбери шрифт с кириллицей, например:

- Consolas  
- Cascadia Mono / Cascadia Code  
- Lucida Console  

Без подходящего шрифта даже правильная кодировка может показать квадратики.

## Вариант A (рекомендуется): `russian_support.h`

Самый удобный способ **на этом курсе**.

### Шаги

1. Файл [`russian_support.h`](russian_support.h) должен лежать рядом с твоим `.cpp` (в корне репозитория он уже есть).
2. В программе:

```cpp
#include <iostream>
#include "russian_support.h"

using namespace std;

int main() {
    setupRussian();  // ВАЖНО: до любого cout / cin

    cout << "Привет, мир!" << endl;

    string name;
    cout << "Введите имя: ";
    cin >> name;
    cout << "Здравствуйте, " << name << "!" << endl;

    return 0;
}
```

3. Сохрани файл в UTF-8 и (в Visual Studio) добавь `/utf-8`.

Полный пример: [`пример_использования_русского.cpp`](пример_использования_русского.cpp)

### Что делает `setupRussian()`

```cpp
SetConsoleOutputCP(65001);  // консоль: вывод в UTF-8
SetConsoleCP(65001);        // консоль: ввод в UTF-8
setlocale(LC_ALL, "Russian");
```

На Linux/macOS внутри заголовка вызывается `setlocale(LC_ALL, "ru_RU.UTF-8")`.

## Вариант B: тот же код прямо в `main`

Если отдельный `.h` файл не нужен — скопируй настройку в программу:

```cpp
#include <iostream>
#include <locale>
#ifdef _WIN32
    #include <windows.h>
#endif

using namespace std;

int main() {
#ifdef _WIN32
    SetConsoleOutputCP(65001);  // UTF-8 вывод
    SetConsoleCP(65001);        // UTF-8 ввод
    setlocale(LC_ALL, "Russian");
#else
    setlocale(LC_ALL, "ru_RU.UTF-8");
#endif

    cout << "Привет, мир!" << endl;
    return 0;
}
```

Плюс: всё в одном файле.  
Минус: придётся копировать в каждую программу.

## Вариант C: только смена кодовой страницы консоли (`chcp`)

Иногда достаточно настроить **окно**, не меняя код.

### Перед запуском программы

1. Открой **Командную строку** (`cmd`).
2. Выполни:

```bat
chcp 65001
```

3. Запусти свою программу из **этого же** окна:

```bat
cd путь\к\папке
имя_программы.exe
```

Или в PowerShell:

```powershell
chcp 65001
.\имя_программы.exe
```

### Важно

- Команда действует **только в текущем окне**.
- Запуск из Visual Studio (F5 / Ctrl+F5) открывает **новое** окно — `chcp` из другого терминала на него не влияет.
- Для запуска из VS всё равно обычно нужны варианты A/B или D.

Проверка текущей страницы:

```bat
chcp
```

- `65001` — UTF-8  
- `866` — DOS-кириллица (старая консоль)  
- `1251` — Windows-1251

## Вариант D: `system("chcp 65001")` из программы

Программа сама переключает консоль:

```cpp
#include <iostream>
#include <cstdlib>   // system

using namespace std;

int main() {
    system("chcp 65001 > nul");  // > nul — не печатать служебное сообщение

    cout << "Привет, мир!" << endl;
    return 0;
}
```

Плюс: просто.  
Минус:

- зависит от `cmd` / окружения;
- менее надёжно, чем `SetConsoleOutputCP`;
- на некоторых системах сообщение `chcp` всё равно мешает.

Можно комбинировать с вариантом B:

```cpp
system("chcp 65001 > nul");
SetConsoleOutputCP(65001);
SetConsoleCP(65001);
```

## Вариант E: Windows-1251 (старый школьный способ)

Раньше в школах часто использовали **CP1251**, а не UTF-8.

### Идея

1. Файл `.cpp` сохранён в **Windows-1251** (не UTF-8!).
2. Консоль переведена на 1251:

```cpp
#include <iostream>
#include <windows.h>

using namespace std;

int main() {
    SetConsoleOutputCP(1251);
    SetConsoleCP(1251);

    cout << "Привет, мир!" << endl;
    return 0;
}
```

Или в `cmd` перед запуском:

```bat
chcp 1251
```

### Когда использовать

- Учитель / старые методички требуют CP1251.
- UTF-8 по какой-то причине не заводится на конкретном ПК.

### Минусы

- Плохо сочетается с современным Git/GitHub (везде UTF-8).
- Легко сломать, если файл случайно сохранить в UTF-8.
- На курсе **предпочтительнее UTF-8** (варианты A/B).

## Вариант F: локаль через `setlocale` / `locale`

### Только `setlocale`

```cpp
#include <iostream>
#include <locale>

using namespace std;

int main() {
    setlocale(LC_ALL, "Russian");
    // или: setlocale(LC_ALL, "ru_RU.UTF-8");
    // или: setlocale(LC_ALL, "");  // системная локаль

    cout << "Привет!" << endl;
    return 0;
}
```

Иногда помогает для форматирования чисел/дат, но **одной локали часто мало** для консоли Windows — буквы всё равно кривые, пока не сменена кодовая страница (65001 или 1251).

### `imbue` для потока

```cpp
#include <iostream>
#include <locale>

using namespace std;

int main() {
    locale::global(locale(""));
    cout.imbue(locale());

    cout << "Привет!" << endl;
    return 0;
}
```

На Windows имя локали может отличаться (`Russian_Russia.1251` и т.п.).  
Для школьного курса обычно достаточно A/B; `imbue` — запасной вариант.

## Вариант G: широкие строки (`wcout`, `L"..."`)

Для полного Unicode иногда используют широкие символы:

```cpp
#include <iostream>
#include <io.h>
#include <fcntl.h>

using namespace std;

int main() {
    _setmode(_fileno(stdout), _O_U16TEXT);

    wcout << L"Привет, мир!" << endl;
    return 0;
}
```

Особенности:

- Пишешь `wcout` и `L"текст"`, а не обычный `cout`.
- Смешивать `cout` и `wcout` в одной программе нельзя / опасно.
- Для курса **не обязательно** — достаточно обычного `cout` + UTF-8.

## Вариант H: Windows Terminal вместо старой консоли

[Windows Terminal](https://aka.ms/terminal) лучше дружит с UTF-8.

1. Установи Windows Terminal из Microsoft Store:  
   [aka.ms/terminal](https://aka.ms/terminal)
2. В настройках профиля поставь шрифт Cascadia.
3. Запускай программу из Terminal после `chcp 65001` **или** используй варианты A/B — тогда и из VS обычно ок.

Это не замена коду, а более удобная оболочка.

## Чеклист и типичные ошибки

### Чеклист

- [ ] `.cpp` сохранён в UTF-8 (или осознанно в CP1251 для варианта E)  
- [ ] В проекте VS добавлен `/utf-8` (для UTF-8)  
- [ ] `setupRussian()` (или аналог) вызван **до первого** `cout`  
- [ ] `#include "russian_support.h"` находит файл (путь верный)  
- [ ] Шрифт консоли поддерживает кириллицу  
- [ ] Проект пересобран после смены настроек (Rebuild)  

### Типичные ошибки

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| `????` вместо букв | Компилятор не в UTF-8 / файл не UTF-8 | UTF-8 + `/utf-8` |
| `РџСЂРёРІРµС‚` (кракозябры) | Файл UTF-8, консоль в CP866/1251 | `SetConsoleOutputCP(65001)` или `chcp 65001` |
| Работает в cmd, но не из VS | Разные окна/кодировки | Вариант A/B внутри программы |
| Ошибка «не найден russian_support.h» | Файл не рядом с `.cpp` | Скопируй `.h` в папку проекта или поправь путь |
| Русский в коде есть, ввод ломается | Не настроен ввод | Нужен ещё `SetConsoleCP(65001)` (есть в `setupRussian`) |
| После `cin` «плывёт» ввод | Смешение `cin` и `getline` | Это другая тема (буфер); к кодировке почти не относится |

### Минимальный тест

```cpp
#include <iostream>
#include "russian_support.h"
using namespace std;

int main() {
    setupRussian();
    cout << "АБВГД абвгд Ёё" << endl;
    return 0;
}
```

Если строка читается нормально — настройка работает.

## Краткая шпаргалка

```text
UTF-8 файл  +  /utf-8  +  setupRussian()   →  обычно достаточно
chcp 65001                                 →  только для текущего окна cmd
CP1251 файл + SetConsoleOutputCP(1251)     →  старый альтернативный путь
wcout + L"..."                             →  продвинутый Unicode, не для старта
```
