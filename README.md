# Курс C++ — Дворец Пионеров

Материалы курса программирования на C++ для школьников 7–10 классов.

---

## Быстрый старт

1. [Установка Visual Studio](ИНСТРУКЦИЯ_УСТАНОВКА_VISUAL_STUDIO.md) — среда и компилятор C++  
2. [Русский язык в консоли](ИНСТРУКЦИЯ_РУССКИЙ_ЯЗЫК.md) — чтобы кириллица отображалась правильно  
3. [Работа с Git](ИНСТРУКЦИЯ_GIT.md) — сохранение кода и отправка на GitHub  
4. Открывай уроки по порядку, начиная с [Урока 1](уроки/урок_01_введение.cpp)

## Как пользоваться уроками

1. Читай теоретическую часть в комментариях в начале файла.  
2. Смотри примеры в `examples()` / в коде урока.  
3. Выполняй упражнения и домашние задания.  
4. До урока 9 блоки `void exerciseN()` — это «коробки с заданием»: пиши код внутри так же, как в `main`.  
5. Иди по порядку: в ДЗ используются только уже изученные темы.
