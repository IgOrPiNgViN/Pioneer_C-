## 1. Что ставим и зачем

Для курса нужна среда, в которой можно:

- писать код C++;
- компилировать (превращать `.cpp` в программу);
- запускать и смотреть вывод в консоли;
- (по желанию) работать с Git.

| Продукт | Для кого | Нужен на курсе? |
|---------|----------|-----------------|
| **Visual Studio Community** | Ученики, школа, личные проекты — **бесплатно** | **Да (рекомендуется)** |
| Visual Studio Professional / Enterprise | Компании, платная лицензия | Нет |
| **Build Tools for Visual Studio** | Только компилятор из командной строки, без удобной IDE | Запасной вариант |
| VS Code + MinGW | Лёгкий редактор + отдельный компилятор | Можно, но в курсе ориентир — Visual Studio |

**Главное:** в установщике отметить рабочую нагрузку  

**Разработка классических приложений на C++**  
(**Desktop development with C++**)

Без этой галочки шаблонов C++ и компилятора MSVC не будет.

> На сайте Microsoft версия может называться Community **2022** или **2026** — для курса подходит любая актуальная **Community**. Важна нагрузка **C++**, а не номер года.

## 2. Системные требования и место на диске

| Параметр | Рекомендация |
|----------|--------------|
| ОС | Windows 10 или Windows 11 |
| ОЗУ | от 8 ГБ (комфортно 16 ГБ) |
| Диск | свободно **не меньше 15–20 ГБ** под VS + C++ (лучше с запасом) |
| Интернет | стабильный: загрузка несколько гигабайт |
| Права | нужны права администратора для установки |

Официально: [Системные требования Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/releases/2022/system-requirements)

### Куда ставить

В установщике можно выбрать диск (например `D:\` вместо `C:\`), если на системном диске мало места:

1. В окне выбора нагрузок нажми **Место установки** / **Installation locations**.
2. Укажи диск с достаточным местом.
3. Вернись к нагрузкам и жми **Установить**.

## Вариант A (рекомендуется): чистая установка Community + C++

Подходит, если Visual Studio ещё **не установлена**.

### Шаг A1. Скачать установщик

1. Открой: [https://visualstudio.microsoft.com/downloads/](https://visualstudio.microsoft.com/downloads/).
2. Найди блок **Visual Studio Community**.
3. Нажми **Free download** / **Бесплатная загрузка** / **Скачать**.
4. Сохрани файл в папку «Загрузки».

Имя файла обычно одно из:

- `VisualStudioSetup.exe`
- `vs_community.exe`
- `vs_Community.exe`

Это **бутстраппер** (маленький установщик): он скачает остальные компоненты уже во время установки.

### Шаг A2. Запустить Visual Studio Installer

1. Дважды кликни по скачанному файлу.
2. Если Windows спросит разрешение (UAC) — нажми **Да**.
3. Дождись, пока установщик себя подготовит.
4. Прими **условия лицензии** и **заявление о конфиденциальности** → **Продолжить** / **Continue**.

Откроется окно **Visual Studio Installer** с вкладками:

- **Рабочие нагрузки** / **Workloads**
- **Отдельные компоненты** / **Individual components**
- **Языковые пакеты** / **Language packs**
- **Место установки** / **Installation locations**

Официально: [Install Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/install/install-visual-studio).

### Шаг A3. Отметить нагрузку C++

1. Вкладка **Рабочие нагрузки**.
2. В группе **Рабочий стол и мобильные приложения** / **Desktop & Mobile** найди:

   **☑ Разработка классических приложений на C++**  
   **☑ Desktop development with C++**

3. Справа откроется панель **Сведения об установке** / **Installation details**.

Для курса достаточно компонентов **по умолчанию**. Обычно там уже есть:

| Компонент | Зачем |
|-----------|--------|
| MSVC (компилятор) | Собирает программу из `.cpp` |
| Windows SDK | Системные заголовки и библиотеки Windows |
| C++ core features | Базовая поддержка C++ в IDE |
| CMake tools (опционально) | Можно оставить; для первых уроков не обязателен |

**Не нужно** специально ставить (если место критично):

- игры (Unreal / Unity);
- мобильную разработку;
- Python / Node.js / веб — если не используешь.

4. (По желанию) вкладка **Языковые пакеты** → отметь **Русский**, если интерфейс хочешь на русском.

5. Нажми **Установить** / **Install**.

### Шаг A4. Дождаться установки

- Индикатор покажет скачивание и установку.
- Время: от **15 минут до 1–2 часов** (зависит от интернета и диска).
- Ноутбук лучше подключить к сети и не выключать экран надолго.
- После завершения можно нажать **Запустить** / **Launch**.

Подробнее про C++: [Install C++ support](https://learn.microsoft.com/ru-ru/cpp/build/vscpp-step-0-installation).

## Вариант B: уже стоит VS, но нет C++

Если Visual Studio установлена (например, только под C#), а шаблонов C++ нет.

### Способ 1 — через Visual Studio Installer

1. Меню Пуск → найди **Visual Studio Installer** → открой.
2. Напротив своей Visual Studio нажми **Изменить** / **Modify**.
3. Отметь **Разработка классических приложений на C++**.
4. **Изменить** / **Modify** → дождись конца.

Официально: [Modify Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/install/modify-visual-studio).

### Способ 2 — из самой Visual Studio

1. Открой Visual Studio.
2. Меню **Средства → Получить средства и компоненты…**  
   (**Tools → Get Tools and Features…**)
3. Откроется тот же Installer → отметь нагрузку C++ → **Изменить**.

### Как понять, что C++ появился

- В **Создать проект** есть шаблон **Консольное приложение** с языком **C++**.
- Или в Installer у нагрузки C++ стоит галочка.

## Вариант C: установка через `winget`

Если удобнее ставить из терминала (Windows 10/11 с [App Installer](https://learn.microsoft.com/ru-ru/windows/package-manager/winget/)).

### 1. Проверить winget

Открой **PowerShell** или **cmd**:

```powershell
winget --version
```

Если команда не найдена — поставь/обнови **App Installer** из Microsoft Store или ставь через **вариант A**.

### 2. Найти пакет Visual Studio

```powershell
winget search "Visual Studio Community"
```

### 3. Установить (пример)

Идентификаторы пакетов Microsoft иногда меняются. Актуальный список смотри в выводе `winget search`. Пример:

```powershell
winget install --id Microsoft.VisualStudio.2022.Community -e
```

или для более новой линейки (если появится в каталоге):

```powershell
winget search Microsoft.VisualStudio.Community
```

После установки **обязательно** открой **Visual Studio Installer** и отметь нагрузку **Desktop development with C++** (сам `winget` часто ставит «скелет» IDE без C++).

Документация: [winget](https://learn.microsoft.com/ru-ru/windows/package-manager/winget/).

## Вариант D: только Build Tools (без полной IDE)

**Build Tools for Visual Studio** — компилятор и инструменты сборки **без** полноценного редактора Visual Studio.

Когда имеет смысл:

- мало места на диске;
- пишешь код в VS Code / Cursor, а компилируешь отдельно;
- нужен только `cl.exe` / MSBuild.

Когда **не** стоит для новичков курса:

- нет удобных кнопок «Создать проект» / «Запуск»;
- сложнее отладка и первые шаги.

### Как поставить

1. Страница [Downloads](https://visualstudio.microsoft.com/downloads/) → раздел **Tools for Visual Studio** → **Build Tools**.
2. Запусти установщик.
3. Отметь **Разработка классических приложений на C++**.
4. Установи.

Официально: [Acquire MSVC](https://learn.microsoft.com/ru-ru/cpp/overview/acquire-msvc).

Для курса всё же лучше **вариант A** (полная Community).

## Вариант E: Visual Studio уже стоит, нужно обновить

1. Открой **Visual Studio Installer**.
2. Если доступно обновление — кнопка **Обновить** / **Update**.
3. Дождись конца (можно продолжать учиться на старой версии, если C++ уже работает).

Официально: [Update Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/install/update-visual-studio).

Обновление полезно при странных ошибках установщика или устаревшем Windows SDK.

## Первый запуск IDE

1. Меню Пуск → **Visual Studio**.
2. Предложат войти в учётную запись Microsoft:
   - можно **войти** (удобно для GitHub / синхронизации);
   - можно **Пропустить / Не сейчас** и войти позже.
3. Выбери оформление (светлая / тёмная тема) — на компиляцию не влияет.
4. Дождись завершения подготовки при первом старте.

**Лицензия Community** бесплатна для обучения и индивидуальных разработчиков. При запросе лицензии выбери Community / учебное использование.

## Создание тестового проекта C++

Проверка: «всё ли поставилось».

Официальный гайд: [Create a C++ console app](https://learn.microsoft.com/ru-ru/cpp/build/vscpp-step-1-create).

### Способ 1 — шаблон «Консольное приложение» (проще)

1. **Файл → Создать → Проект** (`File → New → Project`).
2. В поиске: `консоль` или `console`.
3. Выбери **Консольное приложение** / **Console App**, язык **C++**, платформа **Windows**.
4. Имя, например: `HelloCpp`.
5. Папка проекта — куда удобно (не обязательно OneDrive, если тормозит).
6. **Создать**.

Замени содержимое `main` на:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    return 0;
}
```

### Способ 2 — пустой проект (если шаблона консоли нет)

1. **Создать проект** → **Пустой проект** / **Empty Project** (C++).
2. ПКМ по проекту в обозревателе решений → **Добавить → Создать элемент** → **Файл C++ (.cpp)**.
3. Назови `main.cpp`, вставь код выше.
4. В свойствах проекта: **Linker → System → SubSystem** = **Console** (`/SUBSYSTEM:CONSOLE`), если вдруг собирается как Windows-приложение.

### Запуск

| Действие | Клавиши / кнопка |
|----------|------------------|
| Собрать | **Ctrl+Shift+B** или **Сборка → Собрать решение** |
| Запуск с отладкой | **F5** или зелёная ▶ |
| Запуск без отладки (окно не сразу закрывается) | **Ctrl+F5** |

Если увидел `Hello, C++!` — установка **успешна**.

### Если окно консоли мигает и закрывается

- Запускай через **Ctrl+F5**, не через F5;  
  или в конце `main` временно:

```cpp
system("pause");  // только для теста под Windows
```

## Как открыть файлы уроков курса

Уроки курса — это `.cpp` файлы в папке [`уроки/`](уроки/). Их можно:

### Вариант 1 — открыть файл в существующем проекте

1. Создай консольный проект (как выше).
2. Скопируй нужный `урок_XX_....cpp` в папку проекта **или**  
   ПКМ по проекту → **Добавить → Существующий элемент** → выбери файл урока.
3. Если в проекте два `main` — оставь один (иначе ошибка линковки «уже определён main»).

### Вариант 2 — открыть папку курса

1. **Файл → Открыть → Папка…** → корень репозитория курса.
2. Удобно читать теорию; для запуска всё же удобнее консольный проект (вариант 1).

### Вариант 3 — клонировать репозиторий через Git

См. [ИНСТРУКЦИЯ_GIT.md](ИНСТРУКЦИЯ_GIT.md).

Список уроков со ссылками: [README.md](README.md).

## Русский текст после установки

После того как `Hello, C++!` работает, настрой кириллицу:

→ **[ИНСТРУКЦИЯ_РУССКИЙ_ЯЗЫК.md](ИНСТРУКЦИЯ_РУССКИЙ_ЯЗЫК.md)** — все варианты (UTF-8, `russian_support.h`, `chcp`, CP1251, …)

Кратко для курса:

1. Сохрани `.cpp` в **UTF-8**.
2. В свойствах проекта добавь `/utf-8`  
   (**C/C++ → Командная строка → Дополнительные параметры**).
3. Подключи [`russian_support.h`](russian_support.h) и в начале `main` вызови `setupRussian()`.

## Чеклист и типичные ошибки

### Чеклист установки

- [ ] Скачан установщик с [официального сайта](https://visualstudio.microsoft.com/downloads/)
- [ ] В Installer отмечена нагрузка **Desktop development with C++**
- [ ] Установка дошла до 100% без обрыва
- [ ] Visual Studio запускается
- [ ] Есть шаблон консольного приложения C++ (или пустой проект собирается)
- [ ] Программа вывела `Hello, C++!`
- [ ] (Желательно) настроен [русский вывод](ИНСТРУКЦИЯ_РУССКИЙ_ЯЗЫК.md)
- [ ] (Желательно) разобран [Git](ИНСТРУКЦИЯ_GIT.md)

### Типичные проблемы

| Проблема | Причина | Что сделать |
|----------|---------|-------------|
| Нет шаблона C++ / Console App | Не поставлена нагрузка C++ | Вариант **B** |
| Ошибка `cannot open include file: 'iostream'` | Нет MSVC / Windows SDK | Добавь C++ workload, пересобери |
| Ошибка линковки, два `main` | В проекте несколько файлов с `main` | Оставь один файл с `main` |
| Установщик обрывается | Сеть / антивирус / мало места | Другая сеть, пауза антивируса, другой диск |
| «Не удаётся найти Visual Studio Installer» | Не доустановился бутстраппер | Снова скачай с [downloads](https://visualstudio.microsoft.com/downloads/) |
| Долго «Preparing…» | Нормально при первом запуске / слабом диске | Подождать 10–20 минут |
| Консоль с русским — кракозябры | Кодировка | [ИНСТРУКЦИЯ_РУССКИЙ_ЯЗЫК.md](ИНСТРУКЦИЯ_РУССКИЙ_ЯЗЫК.md) |
| OneDrive блокирует / тормозит сборку | Проект в синхронизируемой папке | Перенеси проект в `C:\Dev\...` вне OneDrive |
| Нужны права администратора | Политика ПК / школьный ноутбук | Попроси учителя / админа |

### Переустановка «с нуля» (крайний случай)

1. **Параметры Windows → Приложения** → удали Visual Studio и Visual Studio Installer.
2. (Опционально) очисти остатки по [документации Microsoft](https://learn.microsoft.com/ru-ru/visualstudio/install/uninstall-visual-studio).
3. Повтори **вариант A**.
